# שמירה אוטומטית לגוגל-דרייב + טבלה — הקמה חד-פעמית (~10 דקות)

כשמתאמן חותם, האפליקציה מייצרת את ה-PDF החתום ושולחת אותו ל"כתובת" קטנה שרצה **בחשבון הגוגל שלך** (Google Apps Script — כלי חינמי של גוגל). הכתובת שומרת את ה-PDF **בתיקייה בדרייב שלך** ורושמת שורה **בגיליון Google Sheet**. הלקוח לא מתחבר לשום דבר, ואין עלות.

## שלב 1 — תיקייה בדרייב
1. היכנס/י ל-[drive.google.com](https://drive.google.com) ← **חדש ▸ תיקייה** (למשל "טפסים חתומים").
2. פתח/י את התיקייה. ה-**ID** נמצא בכתובת: `drive.google.com/drive/folders/`**`XXXXXXXX`** — העתק/י את החלק שאחרי `folders/`.

## שלב 2 — גיליון (טבלת החותמים)
1. ב-[sheets.google.com](https://sheets.google.com) ← **גיליון ריק חדש** (למשל "מעקב חתימות").
2. ה-**ID** בכתובת: `docs.google.com/spreadsheets/d/`**`YYYYYYYY`**`/edit` — העתק/י את החלק שבין `/d/` ל-`/edit`.

## שלב 3 — הסקריפט
1. ב-[script.google.com](https://script.google.com) ← **New project**.
2. מחק/י את הקוד שמופיע, והדבק/י את כל התוכן של [`Code.gs`](./Code.gs).
3. בראש הקובץ, הדבק/י את שני ה-ID-ים:
   ```js
   const FOLDER_ID = 'ה-ID של התיקייה';
   const SHEET_ID  = 'ה-ID של הגיליון';
   ```
4. שמור/י (אייקון הדיסקט).

## שלב 4 — פרסום (Deploy)
1. **Deploy ▸ New deployment**.
2. ליד "Select type" לחץ/י על גלגל השיניים ← **Web app**.
3. הגדרות:
   - **Execute as:** `Me` (החשבון שלך)
   - **Who has access:** `Anyone`
4. **Deploy** ← בפעם הראשונה גוגל תבקש **הרשאה** (Authorize) — אשר/י בחשבון שלך.
5. העתק/י את **Web app URL** (מסתיים ב-`/exec`).

> בדיקה מהירה: הדבק/י את הכתובת בדפדפן — צריך להופיע `{"ok":true,...}`.

## שלב 5 — חיבור לאפליקציה
ב-`index.html`, מצא/י את השורה:
```js
let DRIVE_ENDPOINT = '';
```
והדבק/י בין הגרשיים את כתובת ה-Web App:
```js
let DRIVE_ENDPOINT = 'https://script.google.com/macros/s/.../exec';
```
זהו! מלא/י טופס בדיקה אחד — ה-PDF אמור להופיע בתיקייה, ושורה בגיליון.

---

### 📋 קובץ מוכן להעתקה — `Code.local.gs`
כדי לא לזכור בכל פעם למלא את ה-IDs: הקובץ **[`Code.local.gs`](./Code.local.gs)** הוא בדיוק אותו קוד, אבל עם ה-`FOLDER_ID` וה-`SHEET_ID` שלך **כבר בפנים**. בכל עדכון פשוט מעתיקים את **כל** התוכן שלו, מדביקים ב-`script.google.com`, שומרים, ומפרסמים גרסה חדשה (למטה). הקובץ `Code.gs` הוא רק התבנית הכללית (עם `PASTE_...`) — לתיעוד/לחבר שרוצה להקים מאפס.

### עדכון הסקריפט בעתיד
אם תשנה/י את הקוד, צריך **Deploy ▸ Manage deployments ▸ ✏️ (עריכה) ▸ Version: New version ▸ Deploy** כדי שהשינוי ייכנס לתוקף (הכתובת נשארת אותה כתובת).

### ⚠️ עדכון חשוב — שאלון הפתיחה + תמונת "לפני"
מעכשיו **שאלון הפתיחה** (שהיה בגוגל-פורמז) מובנה בטופס עצמו. כל התשובות נשלחות לגיליון, וגם **תמונת ה"לפני"** (אם המתאמן מעלה אותה) נשמרת בתיקיית הדרייב ומקושרת בשורה.

כדי להפעיל את זה על ההקמה הקיימת שלך:
1. פתח/י את הפרויקט ב-[script.google.com](https://script.google.com), מחק/י את הקוד הישן והדבק/י את התוכן המעודכן של [`Code.gs`](./Code.gs) (ה-`FOLDER_ID` וה-`SHEET_ID` שלך נשארים אותו דבר — פשוט הדבק/י אותם שוב).
2. שמור/י ← **Deploy ▸ Manage deployments ▸ ✏️ ▸ Version: New version ▸ Deploy**.

הגיליון הקיים שלך **יתעדכן אוטומטית**: הסקריפט מוסיף עמודות חדשות מימין (שאלה לכל שאלה בשאלון + "תמונת לפני" + "הערות לקוח") מבלי לפגוע בשורות הישנות. אין צורך למחוק או ליצור גיליון חדש.

### מייל בכל חתימה
בראש הקוד יש קבוע `NOTIFY_EMAIL`. אם ממלאים בו כתובת — נשלח אליך מייל בכל חתימה, עם **ה-PDF מצורף**, כל פרטי המתאמן, סיכום שאלון הפתיחה, וקישורים למסמך ולתמונה. (ב-`Code.local.gs` הכתובת שלך כבר בפנים.) כדי לבטל — משאירים ריק: `const NOTIFY_EMAIL = '';`.

כותרת המייל תמיד בפורמט: **`✍️ טופס חתום חדש — [שם] ([מסלול])`**.

### שהמיילים יכנסו ל"תיקייה" (תווית) ב-Gmail
ב-Gmail אין תיקיות אלא **תוויות (Labels) + מסנן**. הגדרה חד-פעמית:
1. ב-Gmail, בשורת החיפוש למעלה, לחצ/י על סמל המסנן (הפסים) ← בשדה **יש את המילים** כתוב/י: `טופס חתום חדש`
2. **צור מסנן** (Create filter).
3. סמנ/י **החל תווית** ← **תווית חדשה…** ← למשל "חתימות מתאמנים". (אפשר גם לסמן **דלג על תיבת הדואר הנכנס (העבר לארכיון)** אם לא רוצים שזה יופיע ב-Inbox — זה עדיין יופיע תחת התווית.)
4. **צור מסנן**.

מעכשיו כל מייל חתימה חדש ייכנס אוטומטית תחת התווית הזו.

### קישורים לחיצים בגיליון
בעמודות "קישור למסמך" ו"תמונת לפני" מופיע קישור לחיץ (**פתח מסמך** / **פתח תמונה**) במקום כתובת ארוכה. (שורות שנכתבו לפני העדכון נשארות עם הכתובת המלאה — זה לא משפיע על החדשות.)

### הערות
- הכל בחינם (במסגרת המכסות הנדיבות של גוגל).
- אם השליחה האוטומטית נכשלת (למשל אין אינטרנט), הלקוח מקבל כפתורי גיבוי: **שמירת PDF** ו**שליחה בוואטסאפ** — כדי שחתימה לא תאבד.
