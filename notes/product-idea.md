# רעיון המוצר הדיגיטלי — לבנייה בהמשך

_נשמר: 27.10.2026. לחזור לזה כשבונים את המוצר._

## הכיוון הכללי
מעבר ממודל של ליווי אישי לחיילים → **תוכן אורגני ויראלי + מכירת מוצר דיגיטלי שנבנה פעם אחת** (בלי ליווי, משתכפל אינסופית, משתלב עם ג'וב).

## הפסיכולוגיה שמוכרת (הליבה)
לא מוכרים "תוכנית אימון" — מוכרים **זהות**: גוף מרשים + טריקים מגניבים + **הביטחון** של הבחור שיכול לגשת לכל אחת. הקליסטניקס זה הרכב. הסרטונים כבר מוכרים את הפנטזיה; המוצר מגשים אותה.

## המוצר (מה שהוחלט)
מערכת **שלבים מדורגים** (כמו שיטת הדרגות הקיימת, רק שירות-עצמי):
- כל שלב = תוכנית אימון.
- בסוף כל שלב **מבחן כוח** (הצהרה עצמית — הלקוח לוחץ "עברתי → פתח שלב הבא").
- פתיחה אוטומטית של השלב הבא, **בלי ליווי**.
- **יעד סופי כן ובר-השגה:** עמידת ידיים + כמה סקילים ברמה נמוכה + בסיס גוף יפה. (לא מבטיחים פלאנש — זה חודשים.)
- בערך 4–5 שלבים עד היעד (לסגור סופית).

**בונוסים (קיימים מוכנים):** ספר עלייה במסה + ספר חיטוב + ספר מתכונים.

**מסירה:** אזור החברים/מערכת הקורס שכבר בנויה (אתגר 21 יום) — להוסיף גייט "עברתי מבחן → פתח שלב". ניתן לבנות, בלי פלטפורמה חדשה בתשלום.

**מחיר:** ₪99–149 (אימפולס לקהל ויראלי קר; הערך מצדיק את הקצה העליון).

## התוכן (מנוע התנועה)
- רילים: ניגש לבחורה → טריק קליסטניקס על הרצפה (עמידת ידיים, שכיבות בעמידת ידיים/פלאנש, פרס) → **פאנץ' קומי על עצמך** (לא פלקס). זה הוויב — סימפטי ושיתופי.
- שילוב תוכן פיזיק/ערך ("ככה בניתי את זה") כדי שעוקבים יראו בך סמכות ולא רק בידור.
- CTA מתפתח: מ"עקוב" ל**"עקוב → קח את התוכנית שלי"**.

## פתוחים לסגירה כשחוזרים
1. מבנה השלבים המדויק + המבחן של כל שלב.
2. אילו סקילים בסיסיים חוץ מעמידת ידיים.
3. בניית גייט ה"פתח שלב הבא" באזור החברים.
4. ניסוח סיומי הרילים (CTA → מוצר).
5. מחיר סופי + שם המוצר.
