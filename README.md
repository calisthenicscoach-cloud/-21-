# תוכניות אימון — ידיים וכתפיים ב-21 יום 💪

אפליקציית ווב עמוד-יחיד (Single Page App) לקורס הדיגיטלי **"הגדלת ידיים וכתפיים ב-21 יום"**.
המתאמן בוחר את הרמה שלו לפי מבחן כניסה, ומקבל תוכנית אימון מובנית עם קישורי וידאו לכל תרגיל.

## מה יש באפליקציה

- **3 רמות** לפי מבחן מתח / מקבילים / שכיבות שמיכה:
  - רמה 1 · מתחיל (0–3 מתח)
  - רמה 2 · בינוני (4–10 מתח)
  - רמה 3 · מתקדם (11+ מתח)
- **שני מצבי אימון** בכל רמה:
  - **מחולק (A/B)** — אימון דחיפה ואימון משיכה שמתחלפים
  - **אימון מלא** — כל השרירים באימון אחד
- **סופרסטים** עם מספר סבבים ומנוחה מוגדרים
- **RIR** (Reps In Reserve) לכל תרגיל, עם הסבר מובנה
- קישורי וידאו ל**חימום**, ל**טכניקה נכונה**, ולכל תרגיל (כולל חלופות קלות יותר)
- הסבר "איך עובדים עם התוכנית" — חלוקת A/B, כמה אימונים בשבוע, מנוחה

## הצהרת בריאות וחתימה דיגיטלית (חינם, מובנה)

טופס הרשמה בעיצוב צבאי (ירוק זית + זהב, עם סמל MK) שכל מתאמן ממלא לפני תחילת התוכנית. **העיצוב הצבאי חל על מסך ההרשמה בלבד** — שאר האפליקציה נשארת כפי שהיא.

1. **מסלול** — מגיע מהקישור הייעודי (ראה למטה). הלקוח רואה **רק את שם המסלול שלו, בלי מחיר ובלי מסלולים אחרים**.
2. **פרטים אישיים** — שם, ת"ז (עם בדיקת תקינות), תאריך לידה, כתובת, מייל, טלפון; ותמיכה בקטין מתחת ל-18 (חתימת הורה/אפוטרופוס)
3. **שאלון פתיחה** — השאלון שהיה בגוגל-פורמז, כעת מובנה בטופס (רקע אימונים, שגרה, מטרות, תזונה, שינה, פציעות ומגבלות רפואיות, ו**העלאת תמונת "לפני"** אופציונלית). כל התשובות נשלחות אוטומטית לגיליון — **מחליף את הגוגל-פורמז לגמרי**.
4. **שאלון רפואי והצהרת בריאות** — 13 שאלות עם שדה "הערות" לכל תשובה חיובית, ושדה "הערות לקוח"
5. **נוסח ההצהרה** — הצהרת הבריאות וההצהרה האישית (מתוך המסמך של עורך הדין)
6. **קריאת התקנון המלא** — פותח את קובץ ה-PDF המקורי של התקנון לפי המסלול הנבחר
7. **חתימה באצבע** + אישור הצהרת בריאות + אישור תקנון
8. האפליקציה **מייצרת PDF חתום** = הצהרת הבריאות החתומה (עם חותמת תאריך ושעה) **+ התקנון המלא של המסלול** ממוזג לאותו קובץ. שדות בלוק החתימה שבתקנון (שם, ת"ז, תאריך לידה, תאריך, חתימת המתאמן, ו**חתימת העסק**) **מתמלאים אוטומטית**. הקובץ **נשלח אוטומטית לתיקייה בגוגל-דרייב שלך** + רושם שורה ב-Google Sheet (כולל כל תשובות שאלון הפתיחה וקישור לתמונת ה"לפני"). אם השליחה נכשלת — כפתורי גיבוי (שמירת PDF / וואטסאפ, כולל סיכום השאלון).

הכל רץ בדפדפן, ללא שרת, ללא מנוי וללא הגבלת מסמכים — מחליף לגמרי שירות חתימה בתשלום.

### שמירה אוטומטית לגוגל-דרייב + טבלה

כל טופס חתום נשמר אוטומטית כ-PDF בתיקייה בדרייב שלך, ונרשם בגיליון Google Sheet — דרך **Google Apps Script** (חינמי). הקמה חד-פעמית של ~10 דקות: ראה/י **[`apps-script/README.md`](./apps-script/README.md)** להוראות צעד-אחר-צעד + הקוד ב-[`apps-script/Code.gs`](./apps-script/Code.gs). לאחר ההקמה מדביקים את כתובת ה-Web App ב-`index.html` ב-`let DRIVE_ENDPOINT = ''`.

### מסמכי התקנון

התקנונים המקוריים (מעורך הדין) נמצאים בתיקייה [`terms/`](./terms) ומקושרים אוטומטית לפי המסלול:

| מסלול | קובץ |
|---|---|
| מסלול חודש (450 ₪) | `terms/maslul-chodesh.pdf` |
| מסלול 4 חודשים (1,600 ₪) | `terms/maslul-4-chodashim.pdf` |
| מסלול 10 חודשים (3,000 ₪) | `terms/maslul-10-chodashim.pdf` |
| מנוי חודשי מתחדש (450 ₪/חודש) | `terms/maslul-minui-chodshi.pdf` |

לעדכון תקנון — פשוט מחליפים את קובץ ה-PDF המתאים (אותו שם) בתיקייה. הטקסט המשפטי נשאר **מקורי לחלוטין** — האפליקציה רק מקשרת אליו.

### קישור ייעודי לכל מסלול (מה ששולחים ללקוח)

שולחים לכל לקוח את הקישור של המסלול שסגרתם. הטופס נפתח **נעול** למסלול שלו — בלי בורר ובלי מסלולים/מחירים אחרים:

| מסלול | קישור לשליחה |
|---|---|
| מסלול חודש | `…/index.html?maslul=chodesh` |
| מסלול 4 חודשים | `…/index.html?maslul=4` |
| מסלול 10 חודשים | `…/index.html?maslul=10` |
| מנוי חודשי מתחדש | `…/index.html?maslul=minui` |

(פתיחת הקישור הראשי בלי פרמטר מציגה בורר מסלולים — נוח לך לבדיקות.)

## שאלון תזונה (חינם, מובנה) 🥗

דף נפרד — [`tzuna.html`](./tzuna.html) — שמחליף את שאלון התזונה שהיה בגוגל-פורמז. שולחים את הקישור (`…/tzuna.html`) רק למתאמן שרוצה תפריט. אותו עיצוב צבאי כמו טופס החתימה.

המתאמן ממלא ~22 שאלות (פרטים, שירות ולו"ז, שינה/מים, הרגלי אכילה, מזונות/רגישויות, מטרות, ותמונת גוף רשות). בשליחה:

1. נוצר **PDF מסודר** של השאלון ונשמר בתת-תיקייה **"שאלוני תזונה"** בדרייב (יחד עם תמונת הגוף, אם צורפה).
2. נכתבת שורה בלשונית **"תפריט תזונה"** ב-Google Sheet (נוצרת אוטומטית).
3. נשלח **מייל אוטומטי ליועץ התזונה** עם כל התשובות + ה-PDF מצורף, **ועותק אליך**.

עריכת השאלות: במערך `NUTRITION` ב-JS בתוך `tzuna.html` (אותו מבנה כמו `INTAKE`). כתובת ה-Web App (`DRIVE_ENDPOINT`) — אותה כתובת של טופס החתימה. מייל היועץ מוגדר ב-`apps-script/Code.gs` בקבוע `NUTRITION_EMAIL`.

### הגדרה חד-פעמית — מספר הוואטסאפ שלך

בקובץ `index.html`, בתוך ה-`<script>`, יש קבוע:

```js
const COACH_WHATSAPP = '';   // מספר הוואטסאפ שלך בפורמט בינלאומי, ספרות בלבד
```

הזן את המספר שלך בפורמט בינלאומי בלי `+` ובלי `0` בהתחלה — למשל `0501234567` הופך ל-`'972501234567'`.
אם משאירים ריק, וואטסאפ ייפתח והמתאמן יבחר ידנית לאיזה איש קשר לשלוח.

### עריכה

* **מסלולים** — שם/קובץ במערך `TRACKS` ב-JS (מחירים לעיונך בהערה שם, לא מוצגים ללקוח).
* **שאלות רפואיות** — במערך `PARQ` ב-JS.
* **שאלון הפתיחה** — במערך `INTAKE` ב-JS. כל שאלה: `type` = `text` (שורה) / `longtext` (פסקה) / `choice` (בחירה) / `file` (תמונה); ל-`choice` יש `options`, `multi` (בחירה מרובה) ו-`other` ("אחר" עם שדה טקסט); `optional:true` = שאלת רשות. תשובות השאלון נכתבות לגיליון כל אחת בעמודה נפרדת. **לאחר שינוי שם/סדר שאלות — אין צורך לגעת בסקריפט של גוגל; הגיליון מתעדכן אוטומטית.**
* **נוסח ההצהרה** — ב-HTML בתוך `<div id="declText">` (מופיע גם במסמך החתום).
* **סמל MK** — הקובץ `assets/mk-logo.png` (מופיע בראש מסך ההרשמה). העיצוב הצבאי מוגדר בבלוק CSS ממוקד `#signature` — לא משפיע על שאר האפליקציה.
* **חתימת העסק** — הקובץ `assets/business-signature.png` (רקע שקוף). מתמלאת אוטומטית בשדה "חתימת העסק" בכל תקנון. להחלפה — מחליפים את הקובץ (אותו שם). המיקומים של שדות בלוק החתימה בתקנון נמצאים במפה `STAMP` ב-JS.
* הערה: זוהי חתימה אלקטרונית רגילה המתאימה להצהרת בריאות/תקנון בתחום הכושר (אינה מהווה ייעוץ משפטי).

## פריסה (Deploy)

- **Netlify** — לגרור את התיקייה, או לחבר את הריפו. אין צורך בהגדרות (publish directory = השורש).
- כל שרת סטטי אחר (GitHub Pages, Vercel, וכו') יעבוד גם.
