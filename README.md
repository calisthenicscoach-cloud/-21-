# תוכניות אימון — ידיים וכתפיים ב-21 יום 💪

אפליקציית ווב עמוד-יחיד (Single Page App) לקורס הדיגיטלי **"הגדלת ידיים וכתפיים ב-21 יום"**.
המתאמן בוחר את הרמה שלו לפי מבחן כניסה, ומקבל תוכנית אימון מובנית עם קישורי וידאו לכל תרגיל.

## מה יש באפליקציה

- **3 רמות** לפי מבחן מתח / מקבילים / שכיבות שמיכה:
  - רמה 1 · מתחיל (0–3 מתח)
  - רמה 2 · בינוני (4–10 מתח)
  - רמה 3 · מתקדם (11+ מתח)
- **שני מצבי אימון** בכל רמה:
  - **מחולק (A/B)** — אימון דחיפה ואימון משיכה שמתחלפים
  - **אימון מלא** — כל השרירים באימון אחד
- **סופרסטים** עם מספר סבבים ומנוחה מוגדרים
- **RIR** (Reps In Reserve) לכל תרגיל, עם הסבר מובנה
- קישורי וידאו ל**חימום**, ל**טכניקה נכונה**, ולכל תרגיל (כולל חלופות קלות יותר)
- הסבר "איך עובדים עם התוכנית" — חלוקת A/B, כמה אימונים בשבוע, מנוחה

## הצהרת בריאות וחתימה דיגיטלית (חינם, מובנה)

בעמוד הבית יש כפתור **"הצהרת בריאות וחתימה"** — טופס הרשמה שכל מתאמן ממלא לפני תחילת התוכנית:

1. **בחירת מסלול** — 4 מסלולים (חודש · 4 חודשים · 10 חודשים · מנוי חודשי מתחדש)
2. **פרטים אישיים** — שם, ת"ז (עם בדיקת תקינות), תאריך לידה, כתובת, מייל, טלפון; ותמיכה בקטין מתחת ל-18 (חתימת הורה/אפוטרופוס)
3. **שאלון רפואי והצהרת בריאות** — 13 שאלות עם שדה "הערות" לכל תשובה חיובית, ושדה "הערות לקוח"
4. **נוסח ההצהרה** — הצהרת הבריאות וההצהרה האישית (מתוך המסמך של עורך הדין)
5. **קריאת התקנון המלא** — פותח את קובץ ה-PDF המקורי של התקנון לפי המסלול הנבחר
6. **חתימה באצבע** + אישור הצהרת בריאות + אישור תקנון
7. יצירת **מסמך חתום עם חותמת תאריך ושעה**, ושני כפתורים: **שליחה בוואטסאפ למאמן** ו**שמירת PDF**

הכל רץ בדפדפן, ללא שרת, ללא מנוי וללא הגבלת מסמכים — מחליף לגמרי שירות חתימה בתשלום.

### מסמכי התקנון

התקנונים המקוריים (מעורך הדין) נמצאים בתיקייה [`terms/`](./terms) ומקושרים אוטומטית לפי המסלול:

| מסלול | קובץ |
|---|---|
| מסלול חודש (450 ₪) | `terms/maslul-chodesh.pdf` |
| מסלול 4 חודשים (1,600 ₪) | `terms/maslul-4-chodashim.pdf` |
| מסלול 10 חודשים (3,000 ₪) | `terms/maslul-10-chodashim.pdf` |
| מנוי חודשי מתחדש (450 ₪/חודש) | `terms/maslul-minui-chodshi.pdf` |

לעדכון תקנון — פשוט מחליפים את קובץ ה-PDF המתאים (אותו שם) בתיקייה. הטקסט המשפטי נשאר **מקורי לחלוטין** — האפליקציה רק מקשרת אליו.

### הגדרה חד-פעמית — מספר הוואטסאפ שלך

בקובץ `index.html`, בתוך ה-`<script>`, יש קבוע:

```js
const COACH_WHATSAPP = '';   // מספר הוואטסאפ שלך בפורמט בינלאומי, ספרות בלבד
```

הזן את המספר שלך בפורמט בינלאומי בלי `+` ובלי `0` בהתחלה — למשל `0501234567` הופך ל-`'972501234567'`.
אם משאירים ריק, וואטסאפ ייפתח והמתאמן יבחר ידנית לאיזה איש קשר לשלוח.

### עריכה

* **מסלולים** — מחיר/שם/קובץ במערך `TRACKS` ב-JS.
* **שאלות רפואיות** — במערך `PARQ` ב-JS.
* **נוסח ההצהרה** — ב-HTML בתוך `<div id="declText">` (מופיע גם במסמך החתום).
* הערה: זוהי חתימה אלקטרונית רגילה המתאימה להצהרת בריאות/תקנון בתחום הכושר (אינה מהווה ייעוץ משפטי).

## טכני

- קובץ יחיד: [`index.html`](./index.html) — HTML + CSS + JS inline
- ממשק **RTL בעברית**
- ללא תלויות build; התלות החיצונית היחידה היא הפונט Rubik מ-Google Fonts
- קישורי הווידאו מפנים ל-YouTube

## פריסה (Deploy)

האתר סטטי לחלוטין — פשוט מגישים את `index.html` מהשורש:

- **Netlify** — לגרור את התיקייה, או לחבר את הריפו. אין צורך בהגדרות (publish directory = השורש).
- כל שרת סטטי אחר (GitHub Pages, Vercel, וכו') יעבוד גם.
